# mochila-algoritmos-geneticos

Este repositório faz parte de uma atividade da disciplina de Inteligência Artificial no semestre 2025.1.

Desenvolvi uma solução para o problema da mochila (knapsack problem), problema clássico de otimização, utilizando algoritmos genéticos.
Além disso, é possível vizualizar um gráfico de convergência contendo no eixo X o número da geração e no eixo Y,o valor do melhor indivíduo gerado até ali.

***

This repository is part of an assignment for the Artificial Intelligence course in the 2025.1 semester.

I developed a solution for the knapsack problem, a classic optimization problem, using genetic algorithms. Additionally, a convergence graph is available, with the X-axis representing the generation number and the Y-axis showing the value of the best individual generated up to that point.
